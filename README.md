# 💚 Asma-ul-Husna — 99 Names of Allah

An elegant and interactive website dedicated to the **99 Beautiful Names of Allah (Asma-ul-Husna)**. Explore the names, discover their meanings, and take a moment for personal reflection.

## ✨ Features

- **99 Names Collection** — Browse the names in Arabic with their transliterations and meanings.
- **Featured Name** — Discover a name with a reflection and an action for daily life.
- **Shuffle Feature** — Explore a different name.
- **Search** — Search names by Arabic, transliteration, or meaning.
- **Favorites** — Save your favorite names for quick access.
- **Responsive Design** — Use the website on desktop, tablet, and mobile.
- **Elegant Theme** — Emerald green, ivory, and gold color palette.

## 🛠️ Technologies Used

## 🚀 How to Run Locally

1. Download or clone this repository.
2. Open the project folder in Visual Studio Code.
3. Install the **Live Server** extension if you do not already have it.
4. Open `index.html` with Live Server.
5. Explore the website in your browser.
